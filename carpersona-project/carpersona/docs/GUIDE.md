# CAR PERSONA 실행 가이드 (Android가 처음이어도 따라 할 수 있게)

## 0. 준비물
- **Android Studio** (최신, 무료) — https://developer.android.com/studio
- `carpersona-project.zip` (이 프로젝트)
- (선택) Anthropic API 키 — AI 대화를 쓰고 싶을 때만. 없어도 앱은 똑같이 동작합니다.

---

## 1. 프로젝트 열기
1. `carpersona-project.zip`을 **`C:\dev\`** 에 압축 해제합니다. → `C:\dev\carpersona` 폴더가 생깁니다.
   - ⚠ 경로에 **한글이 있으면 Sync가 실패**합니다 (차곡 때 겪은 문제). 꼭 `C:\dev\carpersona` 처럼 영문 경로로.
   - 압축을 풀었더니 `carpersona` 안에 또 `carpersona`가 있으면, **안쪽 폴더**(안에 `app` 폴더와 `settings.gradle.kts`가 보이는 폴더)를 여세요.
2. Android Studio 실행 → **Open** → `C:\dev\carpersona` 선택 → **OK** → "Trust Project?" 창에서 **Trust Project**.
3. 오른쪽 아래 진행 막대가 돌며 **Gradle Sync** (처음 5~10분). 아래 **Build** 창에 초록 체크가 뜨면 성공.

### Sync가 실패하면
- 메시지에 `nexus-playground.pleos.ai`가 보이면 Pleos SDK 저장소 접속 문제입니다.
  1. 왼쪽 파일 목록에서 `gradle.properties` 더블클릭 → 맨 아래 `pleosSdk=true`를 `pleosSdk=false`로 고침
  2. 위쪽 코끼리 아이콘(**Sync Project with Gradle Files**) 클릭
  - 이러면 SDK 없이 빌드되고 **가짜 차** 모드로만 동작합니다 (폰 시연은 문제없음).
- `JDK` 오류면: **File → Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK** 를 `jbr-21` (지금 쓰는 JVM 21)로 선택.
- `com.anthropic` 이 들어간 오류가 나면 캡처해서 보내 주세요 (AI 대화용 라이브러리. 이 부분만 빼고 빌드되게 바로 고칠 수 있어요).

## 2. 폰이나 일반 에뮬레이터에서 실행 (가짜 차 모드)
### 에뮬레이터 (추천: 차 화면처럼 가로로 넓은 태블릿)
1. 오른쪽 위 **Device Manager**(휴대폰 아이콘) → **+** → **Create Virtual Device**
2. **Tablet → Pixel Tablet** → Next → 시스템 이미지 **API 35** 다운로드 → Next → Finish
3. 위쪽 기기 목록에서 만든 기기 선택 → 초록 ▶ **Run 'app'**
- 에뮬레이터에서 목소리가 안 들리면: 에뮬레이터 오른쪽 **⋯ → Settings → 소리**가 켜져 있는지, 그리고 PC 볼륨을 확인하세요.

### 휴대폰
1. 휴대폰 **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호** 7번 눌러 개발자 모드 켜기
2. **설정 → 개발자 옵션 → USB 디버깅** 켜기 → USB로 PC 연결 → "허용"
3. Android Studio 위쪽 기기 목록에서 내 폰 선택 → ▶ **Run 'app'**

## 3. 처음 화면: 차 깨우기
1. 화면 위쪽 오른쪽에 `가짜 차 (시뮬레이터)`가 보이면 정상입니다.
2. 연식(가짜 차는 차대번호에서 2023년식을 읽어 옴)과 누적 주행거리(38,200km)가 미리 채워져 있습니다.
3. **출고일**(자동차 등록증의 최초 등록일, 예: `2023-03-15`)을 넣으면 출고 기념일마다 차가 먼저 축하 인사를 합니다. 비워 두고 나중에 ⚙ 설정에서 넣어도 돼요.
4. "목적지·지역 기록을 이 기기에 저장할게요" 를 켜 둔 채 **✨ 깨우기** → 차가 자기소개를 합니다.

탭 설명
| 탭 | 하는 일 |
|---|---|
| 💬 대화 | 숨 쉬는 얼굴 + 성격 + 지금 기분. 🎙 말하기 / 질문 단추 / 글자로 물어보기 |
| 🌱 성장 기록 | 성격 그래프, "왜 이런 성격일까?"(계산에 쓴 데이터), 차의 기억 |

| 📊 차량 데이터 | 앱이 읽는 Pleos API 값 + AI에게 넘기는 정보 (심사용) |
| 🕹 시뮬레이터 | 가짜 차 조종 (가짜 차일 때만 보임) |
| ⚙ 설정 | 차 이름·연식, 위치 기록 동의, 기억 지우기, 목소리, AI 키 |

## 4. 시연 3개 (🎬 시연 탭)
### ① 같은 질문, 다른 두 차 — "자동차마다 성격이 다른 재미"
1. **① 같은 질문, 다른 두 차** 를 누릅니다. 왼쪽 A차(출고 1년, 여행을 많이 다님), 오른쪽 B차(출고 10년, 출퇴근만 함).
2. 질문 단추 **안녕?** → A차: "오늘은 또 어디로 가? 처음 보는 길이면 더 신나!" / B차: "허허, 오늘도 그 길이구먼. 이 동네는 내가 훤하지."
3. **너는 어떤 차야?** 를 누르면 왜 그런 성격인지 숫자와 함께 설명합니다. 두 차의 목소리 높이·빠르기도 다릅니다.
   - 두 차의 성격 점수는 손으로 넣은 값이 아니라, 각 차의 주행 30일치를 실제로 엔진에 넣어서 계산된 값입니다.

### ② 배터리와 기분 — "살아 있는 존재 같은 경험"
1. **② 배터리와 기분** → **▶ 90% → 20% 자동으로 줄이기**
2. 두 차의 **성격 막대는 움직이지 않고**, 얼굴과 "지금 기분"만 😄 → 🥱 로 바뀝니다.
3. 마지막에 A차 "앗, 나 배터리가 20%밖에 안 남았어! 충전하고 다시 신나게 가자!" / B차 "허허, 오늘은 기운이 좀 없구먼. 배터리가 20% 남았으니 충전 계획을 세워 보세."
4. **타이어 경고** 스위치를 켜면 차가 불편해하면서 `[차량 정보] 타이어 공기압 낮음 — 안전한 곳에 정차해 공기압을 점검하세요.` 를 따로 정확히 말합니다.

### ③ 한 달 여행 후 변화 — "내가 쓰는 방식에 따라 인격이 변하는 신기함"
1. **③ 한 달 여행 후 변화** → **▶ 한 달 여행 빨리 감기** (약 12초)
2. 하루씩 지나며 그래프의 주황 선(모험심)이 오르고 파란 선(익숙함 사랑)이 내려갑니다. 갑자기가 아니라 조금씩.
   - 확인한 값: 모험심 14 → 59, 익숙함 사랑 97 → 52, 성격 이름 "동네 터줏대감" → "전국을 누빈 방랑 시인"
3. 끝나면 B차가 말합니다: "예전에는 매일 같은 길이었는데, 요즘은 처음 가는 곳이 많아졌구먼. 늘그막에 모험가가 된 기분일세."
4. 말투(어르신 말투)는 연식·주행거리로 정해져서 바뀌지 않습니다. 성격만 바뀌어요.

### ④ 기념일 — 1만 km·출고 기념일에 차가 먼저 말하기
1. **④ 기념일** → **🎉 다음 1만 km 넘기** 또는 **🎂 출고 기념일**
2. A차는 높고 빠른 "띠리링!", B차는 낮고 느린 "댕-, 댕-" 알림음이 울린 뒤 각자 말합니다.
   - A차(새내기 탐험가): "나 오늘 2만 km 넘었어! 그동안 16곳이나 가 봤지! 다음 1만 km는 더 멀리 가 보자!"
   - B차(동네 터줏대감): "허허, 나 오늘 17만 km를 넘었구먼. 그 가운데 회사 가는 길이 제일 많았지. 그 길은 이제 내 손금 같다네."
   - 출고 기념일: A차 "나 벌써 2살 됐어! 지난 1년 동안 17곳을 처음 가 봤어. 올해도 새로운 데 많이 가자!" / B차 "허허, 나 벌써 11살이 됐구먼. 올해도 다니던 그 길, 잘 부탁하네."
   - 시연 ③으로 한 달 여행을 다닌 B차는 같은 기념일에도 "15곳이나 돌아다녔으니 이만하면 방랑객이지." 처럼 바뀐 성격대로 말해요.

기념일 규칙 (내 차)
| 기념일 | 언제 | 차가 하는 말 |
|---|---|---|
| 🎉 1만 km | 누적 주행거리가 1만 km 단위를 넘는 순간 (주행 중이어도) | "나 오늘 {n}만 km 넘었어" + 성격에 맞는 한마디 |
| 🎂 출고 기념일 | 출고일로부터 1년마다, 그날 처음 앱이 켜져 있을 때 (7일 안이면 늦게라도) | "나 벌써 {n}살 됐어" + 성격에 맞는 한마디 |
- 말투(새내기·친구·어르신)는 연식·주행거리로, 덧붙이는 한마디는 대표 성격(모험심 → 다녀 본 지역 수, 익숙함 → 제일 많이 간 곳, 활동성 → 이번 1만 km에 걸린 날 수·1년 주행 횟수)으로 정해집니다.
- 운전 중에는 두 문장까지만 말합니다. 앱 설치 전에 이미 지난 기념일은 축하하지 않고, 한 번에 2만 km 이상 뛰는 값(처음 차 값을 받을 때 등)도 축하하지 않습니다.
- 알림음은 ⚙ 설정의 "차가 목소리로 말하기"가 켜져 있을 때만 울립니다.

## 5. 내 차로 해 보기 (🕹 시뮬레이터 탭)
1. **1. 출발** 에서 `강릉 경포해변` 같은 곳을 누르면 출발 → 차가 먼저 말을 겁니다 ("…처음 가 보는 곳이네! 신난다!").
   - 💬 대화 탭으로 가 보면 "주행 중"이라 글자 입력칸이 사라지고, 차의 말이 한 문장으로 짧아집니다.
2. 약 20초 뒤 자동 도착 → "강릉 처음 와 봤어! 오늘 일 꼭 기억할게!" + 🌱 성장 기록에 기억이 남습니다.
3. **🔋 −20%** 를 몇 번 누르면 25% 아래로 떨어지는 순간 차가 배고파합니다. **⚠ 타이어 공기압 낮음** 을 누르면 바로 경고를 말합니다.
4. **3. 기념일**: `🎉 1만 km 직전으로` → 아무 목적지로 출발하면 곧 1만 km를 넘으며 알림음 + 축하 / `🎂 다음 출고 기념일로 시계 이동` → 1분 뒤 알림음 + "나 벌써 {n}살 됐어"
5. **빨리 감기**: `🏢 출퇴근 1주` 를 여러 번 → 익숙함 사랑이 오름 / `🗺 전국 여행 2주` → 모험심이 오름. 끝나면 차가 변화를 이야기합니다.

## 6. AI 대화 켜기 (선택)
키가 없어도 규칙 기반 대사로 똑같이 동작합니다. AI를 켜면 정해진 문장이 아니라 그때그때 새로운 말을 합니다.
1. https://console.anthropic.com 로그인 → 왼쪽 **API Keys** → **Create Key** → 이름 `carpersona` → 생성된 `sk-ant-...` 키 복사
   - 결제 수단(크레딧)을 등록해야 동작합니다. 대화 한 번에 드는 비용은 아주 작지만, 팀에서 한도를 정해 두세요 (**Settings → Limits**).
2. 앱 **⚙ 설정 → AI 대화** 에 붙여 넣고 **키 저장**. "AI로 대답하기"가 켜져 있는지 확인.
3. 💬 대화에서 질문하면 말풍선 아래에 `Claude AI` 표시가 붙습니다. 10초 안에 답이 없거나 인터넷이 끊기면 자동으로 기본 대사로 답합니다.
- ⚠ **키를 코드나 GitHub에 절대 넣지 마세요.** 공개 저장소에 올라가면 바로 도용됩니다. 키는 앱 설정 화면에만 넣습니다.
- 사용 모델: `claude-opus-5-5` (짧은 답이라 effort LOW). 바꾸려면 `ai/ClaudeBrain.kt` 의 `MODEL`.
- AI에게 무엇을 보내는지는 📊 차량 데이터 탭 맨 아래 "AI에게 넘기는 정보"에 그대로 보입니다 (성격 점수·기분·최근 기억 6개·차 상태).

## 7. Pleos 에뮬레이터에서 실행 (진짜 차 데이터)
1. Pleos Connect 에뮬레이터(Automotive, API 34)를 공식 문서대로 켭니다 (이미 설치한 v2.1.0).
2. `gradle.properties`가 `pleosSdk=true` 인지 확인 → Sync → 기기 목록에서 Pleos 에뮬레이터 선택 → ▶ Run
3. 앱 위쪽에 `Pleos 차량` 이 보이면 연결 성공. 6초 동안 값이 안 오면 자동으로 가짜 차로 바뀌고 📊 차량 데이터 탭에 이유가 적힙니다.
4. 📊 차량 데이터 탭에서 확인할 것 (결과를 알려 주세요):
   - `getCurrentDistanceDriven` (누적 주행거리) 값과 단위 — 200만이 넘으면 m로 보고 자동으로 km로 바꿉니다.
   - `getVINInfo` (차대번호) — 17자리로 오면 연식을 자동으로 읽습니다. 이상하면 처음 화면/설정에서 연식을 직접 고치면 됩니다.
   - 배터리(`getEvBatteryStateOfCharge`) 또는 연료(`getFuelPercent`) 중 어느 쪽이 오는지.
5. 에뮬레이터 내비에서 목적지를 정하고 주행 시뮬레이션 → 차가 출발 인사 → 도착하면 기억이 남습니다.
   - 주행 여부는 속도 API가 없어서 "이번 주행 거리·시간이 늘어나는지"로 판단합니다. 3분 동안 안 늘면 주행이 끝난 것으로 봅니다.
> 어떤 값이 안 들어오는지는 Android Studio 아래쪽 **Logcat**에서 `CarPersona` 로 검색하면 보입니다.

## 8. GitHub에 올리고 APK 자동으로 받기
차곡과 같은 방식입니다. 이번 앱이 메인 출품작이니 **새 저장소**를 추천합니다.
1. github.com → 오른쪽 위 **+** → **New repository** → 이름 `CarPersona` → **Public** → **Create repository**
2. **uploading an existing file** 링크 → 탐색기에서 `C:\dev\carpersona` 안의 내용을 모두 끌어다 놓기 → 아래 **Commit changes**
3. 숨김 폴더는 끌어다 놓기로 안 올라갈 수 있어요. 저장소에 `.github` 와 `.gitignore` 가 안 보이면:
   - **Add file → Create new file** → 이름 칸에 `.github/workflows/build-apk.yml` 입력 → 함께 드린 `build-apk.yml` 내용을 붙여 넣기 → **Commit changes**
   - 다시 **Add file → Create new file** → 이름 `.gitignore` → 함께 드린 `gitignore.txt` 내용 붙여 넣기 → **Commit changes**
4. 저장소 위쪽 **Actions** 탭 → "Build APK" 가 노란 점(진행) → 초록 ✓ (3~5분)
5. 끝나면 `apk/carpersona.apk` 가 저장소에 생기고, 오른쪽 **Releases → latest** 에도 붙습니다. 이 링크를 신청서 7번(참고자료)에 넣으면 됩니다.
   - 빨간 ✗ 이면 Actions 화면 주소나 캡처를 보내 주세요.
6. 친구(팀원)와 같이 고치려면 저장소 **Settings → Collaborators → Add people**.
7. 이후 코드를 고칠 땐 Android Studio에서 이 저장소를 clone 한 폴더로 작업하고, push 전에 꼭 Pull (봇이 APK를 커밋하기 때문).

## 10. 아직 확인 못 한 것 (솔직하게)
- 이 클라우드 환경은 Google 저장소가 막혀 **APK를 직접 빌드해 보지 못했습니다.** 코드는 같은 Kotlin/Compose 버전으로 컴파일 검사를 통과했고,
  시연 3개의 대사와 성격 수치는 실제로 엔진을 돌려서 확인했습니다. 첫 빌드는 GitHub Actions나 Android Studio에서 확인해 주세요.
- AI 대화 라이브러리(공식 Anthropic Java SDK)가 안드로이드에서 문제를 일으키면 알려 주세요. 그 경우에도 앱은 기본 대사로 동작하게 고칠 수 있습니다.
- Pleos 에뮬레이터에서 `getVINInfo`·`getCurrentDistanceDriven` 이 실제로 어떤 값을 주는지, `NAVI_ROUTE` 권한 이름이 맞는지.
- 성격 가중치(`persona/PersonaEngine.kt` 맨 위 상수와 `target()`)는 프로토타입용 설계값입니다. 제안서 8장 6단계처럼 시연하며 조정하세요.
